The problem

GitHub has no API for uploading images to issues or PRs. The feature request has been open since 2020. The gh CLI team closed it. The upload endpoint requires browser session cookies, not API tokens.


If you work in the terminal — over SSH, in CI, in a container — there's no way to attach a screenshot to an issue without opening a browser. gitshot fixes that.

How it works

Three steps, one command. Uses the official GitHub Releases API — no browser automation, no undocumented endpoints.

1
Run gitshot
Pass your image file. gitshot detects the best upload backend automatically — GitHub Releases if you have gh authenticated, or Catbox.moe as a zero-config fallback.
2
Image uploaded
Your image is uploaded as a GitHub Release asset to a dedicated gitshot-images repo (auto-created on first use). The URL is permanent and CDN-backed.
3
Markdown returned
The markdown image link is printed to stdout. Pipe it into gh pr comment, gh issue create, or use it anywhere GitHub renders markdown.

Features

Zero dependencies
Uses only Node.js built-ins: fetch, crypto, fs, child_process. No axios, no node-fetch. npm install is instant.
4 upload backends
GitHub Releases (default), Catbox.moe (fallback), Cloudinary (CDN), imgbb (free). Auto-detects the best available option.
Agent-friendly
Clean stdout (URLs only), stderr for logs, --json mode, no interactive prompts. Built for Claude, Cursor, Copilot, and any AI agent.
Works over SSH
No browser, no display server, no Xvfb. Works in SSH sessions, Docker containers, Codespaces, and any CI/CD pipeline.
Composable
Pipe output into any gh command. gitshot img.png | gh pr comment 42 --body-file -
10 image formats
PNG, JPG, JPEG, GIF, SVG, WebP, BMP, ICO, TIFF, AVIF. Auto-detected from file extension.

Usage

Examples 
# Upload an image — returns markdown
$ gitshot rick.gif
![screenshot](https://github.com/you/gitshot-images/releases/download/_gitshot/screenshot-a1b2c3d4.png)

# Comment on a PR with the image
$ gitshot fix.png | gh pr comment 42 --body-file -

# Create an issue with a screenshot
$ gitshot bug.png | gh issue create --title "Bug" --body-file -

# Raw URL for scripting
$ gitshot --raw rick.gif
https://github.com/you/gitshot-images/releases/download/_gitshot/screenshot-a1b2c3d4.png

# JSON output for AI agents
$ gitshot --json rick.gif
{"url":"https://...","markdown":"![...](...)","backend":"release"}

# Use a specific backend
$ gitshot --backend catbox rick.gif

# Multiple images
$ gitshot before.png after.png

Install

Three ways to get started.

Instant (npx)

npx gitshot rick.gif

Global install

npm install -g gitshot

gh CLI extension

gh extension install vipulgupta2048/gitshot
